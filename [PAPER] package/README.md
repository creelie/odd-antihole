# Every odd antihole is strongly chromatic-choosable

Submission package v1.2.0, 26 October 2026. Authors: Deep Bhattacharjee and Ushashi Bhattacharya.

Target journal: **Journal of Graph Theory**. No journal submission has been made by this packaging work.

## Main files

- `OddAntiholeConjecture.pdf`: manuscript, single column, no marginal line numbers.
- `OddAntiholeConjecturetex.zip`: portable TeX sources for Overleaf and Hexagon; created only after the new Zenodo DOI is confirmed.
- `hexagonsubmissionform.md`: copy-ready fields and existing preprint identifier.
- `aiprovinance.md`: provenance and the retained human-understanding declaration.
- `journalsubmissiondetails.md`: journal portal, scope and submission checklist.
- `coverletterjournal.pdf` and `coverlettertex.zip`: prepared cover letter and TeX source.
- `journalaideclarationform.pdf`: prepared AI disclosure statement, not a signed publisher-issued form.
- `FORMAL-SCOPE.md`: precise verification scope.
- `DOI-RECEIPT.json` and `RELEASE-DOI.md`: final archival evidence, added after publication.
- `PACKAGE-MANIFEST.json`: checksums for the final package.

The manuscript supplies a general proof for every integer ell >= 3. Its path and cycle lemmas lead to the main list-colouring theorem. The critical-graph consequence is proved in the manuscript, with its source credited to Fiujlaali and McDonald.

The existing preprint is https://hexagonmath.org/2610.00319v1. The intended Hexagon revision is v2; it has not been submitted by this work. The author has no arXiv identifier for this paper.

The journal and Hexagon manuscripts are the same PDF and source. Formalisation files are linked through the existing repository rather than included in the Hexagon TeX ZIP. Original verification code remains in the repository.

Confirmed archive: https://doi.org/10.5281/zenodo.23662269
